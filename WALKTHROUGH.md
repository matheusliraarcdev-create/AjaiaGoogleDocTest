# Walkthrough script

Aim for 3–5 minutes. Sign in with the buttons on the login screen. The password for every account is `folio-demo`.

1. Start on the sign-in screen. Say what Folio is: a shared draft editor, not a full Google Docs clone. Point at the three seeded teammates.
2. Sign in as Ada. Show **Your documents** and the empty **Shared with you** section. Open **Product kickoff notes**. Apply bold or a heading, wait for **Saved**, and refresh. The formatting is still there.
3. Open **Share**. Show Lin's edit access. Give Noah view access. Explain that edit is the default because the tool is for drafting, and view is for read-only circulation. Only the owner can change this.
4. Sign out and sign in as Noah. The kickoff notes are under **Shared with you** with a **Can view** badge. Open it and show the read-only banner. There is no formatting toolbar.
5. Sign in as Lin and show that the same document is editable, while sharing stays with Ada.
6. Import `samples/weekly-update.md` or `samples/word-notes.docx`. Say that `.txt`, `.md`, and `.docx` up to 2 MB become a new document, and other types are rejected.
7. Close on the cuts: no realtime cursors, comments, or version history. The last save wins if two people edit. Say that the next few hours would go to version snapshots and Markdown export.
8. Mention the AI workflow in one or two sentences: Cursor drafted the app, and the rename bug, the editor crash from raw database rows, and the invalid Word sample were found by running the product and then fixed.
